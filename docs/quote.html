Check a quote

Sayings of Spurgeon, Luther, Augustine and other older writers, checked against their books. Searches aren’t logged.

Give your AI app the books themselves. Connect the library to Claude, ChatGPT, Gemini or Grok. It then searches all 7,700 works and quotes the passage with its source, not from memory. Free.

Set it up

How to read the results

The answer is where the words come from: a Bible verse, or the earliest book in the library that has them, with its own wording, page and a link to the source. It is found by comparing your words with the books’ text, word by word. No AI writes it.

If you give a name and none of that writer’s works has the words, the answer says so. If the book’s wording differs from yours, it says that too. If no book has the words, it says they are not in the library, and if the name is a writer whose books are still in copyright, it says that instead.

Limits of this search
  • It can’t check present-day writers. Most books published after 1930 are still in copyright, so the library doesn’t have them: not C. S. Lewis, A. W. Tozer, John Piper or Tim Keller.
  • “Not found” does not mean false. The library holds about 7,700 works, not everything ever written.
  • The earliest work in the library is not always the origin. A saying can be older than any book the library holds.
  • Scanned texts contain misread letters. Where a text was read by computer from a scan, compare the printed page before quoting it.
  • The checker can be wrong. If an answer looks wrong, use Think this answer is wrong? Tell us under it. Fixes are listed in the corrections log.

See also Accuracy

Privacy

The words you check go to the library's server and to Voyage AI, whose search index helps locate reworded passages. Cloudflare carries them. Neither keeps a record of them. So that a shared result opens quickly, the server keeps each answer for a day, sealed so that only someone checking the same words can open it. A share link carries the quotation inside the link itself, after the #, so this website never receives it. Your IP address is used only to count checks for the daily limit, as a scrambled code that changes every day and is deleted the next day. Details.
