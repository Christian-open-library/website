Set it up

  • About 5 minutes
  • Claude, ChatGPT, Gemini
  • Email sign-in

Four steps: copy the address, add it to your AI app, sign in with your email, and let it search. You don't need a GitHub account.

1. Copy the address

https://mcp.christianopenlibrary.org/mcp

2. Add it to your AI app

  • Claude
  • ChatGPT
  • Gemini

Claude

  1. Open Settings › Connectors.
  2. Choose Add custom connector.
  3. Paste the address and choose Connect.

ChatGPT paid plans

  1. Open Settings › Apps & Connectors.
  2. Turn on Developer mode, then choose Create.
  3. Paste the address, choose OAuth for sign-in, and save.

Gemini

  1. Open Settings › Connected Apps.
  2. Choose Add a custom app.
  3. Paste the address.

Can't find these menus? Their names change from time to time. Look in your app's settings for "connectors" or "MCP".

3. Sign in

  1. A sign-in page opens. Type your email address.
  2. Type in the code that's emailed to you.

You can sign in with GitHub instead, but you don't need to. Sign-in is handled by WorkOS: see what happens to your question.

4. Let it search without asking

The first time your app uses the library, it may ask whether to allow it. The library only reads books: it can't change, send or delete anything. So it's safe to let it run without asking each time.

  • Claude: when it asks, choose Always allow. To set this ahead of time, open Settings › Connectors, choose the library, and set its tools to Always allow. If Claude keeps asking anyway, set it there again.
  • ChatGPT: the library's tools are marked read-only, so it usually won't ask. If it does, choose Confirm.
  • Gemini: if it asks, choose to allow it.

Prefer to approve each search? Leave it on Needs approval. Don't choose Blocked or Never: then the library can't answer at all.

Then ask a question

Start a new conversation. If your app has a tools or connectors button near the message box, make sure the library is switched on. Then ask, for example:

  • Search the Christian Open Library: what did Calvin teach about the Lord's Supper?
  • What did Spurgeon say about Psalm 23?
  • Which historic writers cited Isaiah 53?

Naming the library in your first question helps your app know to use it.

Good to know

  • Your AI app writes the answer. Check a quotation against its source before you print or use it. How to check it.
  • If you remember only the gist, try two or three phrasings, or one distinctive phrase.
  • Each person has a fair-use daily limit.
  • Stuck? Write to hello@christianopenlibrary.org and say which app you use.
