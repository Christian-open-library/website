Set it up

1. Copy the address

https://mcp.christianopenlibrary.org/mcp

2. Add it to your AI app

Claude

  1. Open Settings › Connectors.
  2. Choose Add custom connector.
  3. Paste the address and choose Connect.

ChatGPT

  1. Open Settings › Apps & Connectors.
  2. Turn on Developer mode, then choose Create.
  3. Paste the address, choose OAuth for sign-in, and save.

On paid plans only.

Gemini

  1. Open Settings › Connected Apps.
  2. Choose Add a custom app.
  3. Paste the address.

Grok

  1. Go to grok.com/connectors.
  2. Choose New Connector, then Custom.
  3. Paste the address and save.

Menu names change from time to time. If one is missing, look in your app's settings for "connectors" or "MCP".

3. Sign in

A sign-in page opens. Type your email address and then the code emailed to you. Or choose Continue with Google or GitHub.

Sign-in is handled by WorkOS: see what happens to your question.

4. Let it search without asking

The library only reads books. It can't change, send or delete anything. It's safe to let it run.

  • Claude: When it asks, choose Always allow. Or set it ahead of time. Go to Settings › Connectors, choose the library and set its tools to Always allow. If Claude keeps asking, set it there again.
  • ChatGPT: The library's tools are marked read-only. It usually won't ask. If it does, choose Confirm.
  • Gemini: If it asks, choose to allow it.
  • Grok: If it asks, choose to allow it.

To approve each search yourself, leave it on Needs approval. Blocked or Never stops the library answering at all.

Then ask

Start a new chat. If your app has a tools button by the message box, check the library is switched on. Naming it in your first question helps:

  • Search the Christian Open Library: what did Calvin teach about the Lord's Supper?
  • What did Spurgeon say about Psalm 23?
  • Which historic writers cited Isaiah 53?

Using the connector

It's free for your own study, teaching, preaching and writing. Quote what it finds and give the source.

Don't run it behind another app, website, bot or AI service. Don't share your account. Don't use it to copy texts out in bulk or for AI training. Some documents are here by their owners' permission. Quote only what you need from them and credit the church body. Never copy one whole. You need a written license to use more than 10 books or to use them in something paid. Write to hello@christianopenlibrary.org. All the rules.

Accounts used against these rules are closed. An account that reads far more of the library than study needs is paused.

Good to know

  • Your AI app writes the answer. Check a quotation against its source before you print or use it. How to check it.
  • Remember only the gist? Try two or three phrasings or one distinctive phrase.
  • Each person has daily limits: one for requests and one for passages read in full.
  • Stuck? Write to hello@christianopenlibrary.org and say which app you use.
