Supporting the library

The library is free, with no ads and nothing for sale. It costs a little each month to run. If it's useful to you, you can help.

Give through GitHub Sponsors

What it costs this month

This card updates every night from the actual bills and gifts.

What the money goes to

  • Searches: each question is matched by meaning through Voyage AI, which charges by the amount of text it reads. This grows with use.
  • Adding new books: every new book is read once by Voyage AI so it can be searched.
  • The server: a small computer that runs around the clock, and its electricity.
  • The domain name: christianopenlibrary.org.

The time spent finding, checking and adding books isn't on the card.

How to give

GitHub Sponsors takes gifts monthly or once, by card. You need a free GitHub account.

Gifts go to me, Matt Miller, personally, to support my work on the library. They are not tax-deductible, and the library is not a charity or a ministry of any church. Giving is never needed to use it.
