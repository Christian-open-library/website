Download the books

  • 9,700 files
  • About 3 GB
  • Free GitHub account

The connector lets you search the library from your AI app. If you'd rather have the books themselves on your own computer, you can download a single book or the whole library.

What you get

  • About 4,600 works in 9,700 files. Each book is a Markdown file: plain text with simple formatting, which opens in any text editor and in note apps such as Obsidian.
  • About 3 GB for the whole library, once unzipped.
  • Long books are split into parts. Open the file without "Part" in its name: it links to each part.
  • Every file names its source and license at the top, so you can see which edition you are reading.

Getting access

The books are shared by invitation, through GitHub. This is the one part of the library that needs a free GitHub account.

  1. Make a free account at github.com if you don't have one.
  2. Ask for an invitation with the request form. The form is public, so don't put your email address or other private details in it.
  3. Accept the invitation. GitHub emails it to you. You can also open github.com/Christian-open-library and choose Accept invitation.

You don't need an invitation to use the AI connector. Anyone can set that up with just an email address.

Download one book

  1. Find the book in the catalog. GitHub shows it as a table with a search box. Old books use old spelling, so search for one distinctive word, such as Baxter or Saints Rest. The Folder column says where the book is.
  2. Open that folder in the library at github.com/Christian-open-library/books, and click the book.
  3. Choose the download button (Download raw file) at the top right of the book.

Download the whole library

Once

  1. Go to github.com/Christian-open-library/books.
  2. Choose the green Code button, then Download ZIP.
  3. Unzip it. You now have a folder of books.

To get books added later, download the ZIP again.

And keep it up to date

  1. Install GitHub Desktop and sign in.
  2. On the library's page, choose Code, then Open with GitHub Desktop. Pick where to save it and choose Clone.
  3. To get new books later, open GitHub Desktop and choose Fetch origin, then Pull origin.

Reading them in Obsidian

Drag the library folder into your vault, or open it as its own vault with Open folder as vault. For a long book, open the note without "Part" in its name: it links to each part.

What you may do with them

  • Most books are in the public domain. Read them, quote them, print them and share them.
  • Texts from the Christian Classics Ethereal Library may be quoted and used freely, as long as the files are not sold.
  • The Greek and Latin texts from the Open Greek and Latin Project are licensed CC BY-SA 4.0. If you share them, credit the project and share them under the same license.
